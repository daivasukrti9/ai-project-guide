⚙️ Configuración global — skills, plugins y MCP

Antes de pegar el prompt, conoce estas tres piezas:

  • Skill: instrucción reutilizable (como esta guía). En Claude Code va en .claude/skills/; en Claude web/desktop, en tus instrucciones personalizadas.
  • Plugin: paquete que agrupa varias skills, comandos y a veces un MCP — se instala una sola vez.
  • MCP (Model Context Protocol): conexión técnica real a una herramienta externa (Drive, una base de datos, un servicio). Requiere revisión de seguridad antes de activarlo.

🛡️ Regla fija: no instales ni actives nada de esto sin revisar antes qué permisos pide y qué datos puede tocar.
